# Tacoma Housing Price Prediction & Deployment

## Overview

Built a machine learning model to predict Tacoma home prices using property characteristics, location variables, and housing amenities.

## Tools Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Joblib

## Project Highlights

* Cleaned and analyzed 4,500+ housing records
* Performed feature engineering and categorical encoding
* Built Multiple Linear Regression and LASSO Regression models
* Evaluated model performance using RMSE and R²
* Deployed an interactive Streamlit application for real-time predictions
